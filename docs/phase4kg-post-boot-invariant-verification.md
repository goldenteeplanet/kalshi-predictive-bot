# Phase 4KG: Post-boot invariant verification

Phase 4KG binds post-boot continuation to the content-addressed protected-invariant snapshot. It requires the Phase 4KF database prerequisite and verifies the exact paper-only production counts, identifiers, filled order, forecast, fill count, and Phase 3M/3N maxima established by the recovery safety contract.

Stale or incomplete evidence blocks the chain; any protected-value drift fails it. The result is deterministic, read-only, and grants no database-write, recovery, restart, service-control, or execution authority. It evaluates existing evidence only and performs no database or host operation.
