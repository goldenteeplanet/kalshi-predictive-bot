# Phase 4AJ independent proposal review

Phase 4AJ independently reviews a Phase 4AI canonicalization proposal without executing or
authorizing it. It recomputes all artifact and row hashes, reconstructs the Phase 4AC history,
validates the Phase 4AD–4AH lineage, checks proposal expiration, and re-reads each current
settlement through SQLite URI `mode=ro` with `PRAGMA query_only=ON` enforced.

The review-state precedence is `LINEAGE_FAILURE`, `PROPOSAL_TAMPERED`, `PROPOSAL_EXPIRED`,
`CURRENT_STATE_DRIFTED`, `EVIDENCE_CONFLICT`, `HUMAN_APPROVAL_INVALID`, `REJECTED`,
`AWAITING_HUMAN_APPROVAL`, `APPROVED_FOR_SEPARATELY_AUTHORIZED_EXECUTION`, then
`NO_ELIGIBLE_ROWS`. Structural or cryptographic tampering raises a fail-closed validation error
before publication; semantic review failures use the corresponding state.

Human approval is never generated by Phase 4AJ. An optional
`phase4aj.human-approval.v1` artifact must bind exactly to the Phase 4AI proposal hash, review
manifest hash, and complete eligible proposal-row hash set. It must have a nonempty reviewer,
timezone-aware approval and expiration times, future-separate-execution scope, and
`phase4aj_execution_authorized=false`. Missing approval leaves valid rows awaiting review;
invalid, expired, future-dated, partial, or overbroad approval fails closed.

Technical readiness, human approval, and execution authorization are separate facts.
`APPROVED_FOR_SEPARATELY_AUTHORIZED_EXECUTION` only permits a later phase to consider the
reviewed rows. Both Phase 4AJ outputs always contain `execution_authorized=false`, and the
attestation always contains `database_mutation_performed=false`.

```bash
PYTHONPATH=src python scripts/local/phase4aj_independent_proposal_review.py \
  --phase4ai-proposal /tmp/phase4ai-proposal.json \
  --phase4ai-review-manifest /tmp/phase4ai-review.json \
  --phase4ah-gate-artifact /tmp/phase4ah-gate.json \
  --phase4af-reaudit-artifact /tmp/phase4af-reaudit.json \
  --baseline-phase4af-artifact /tmp/phase4af.json \
  --phase4ag-status-artifact /tmp/phase4ag-status.json \
  --phase4ag-evidence-artifact /tmp/phase4ag-evidence.json \
  --phase4ad-artifact /tmp/phase4ad.json \
  --phase4ae-artifact /tmp/phase4ae.json \
  --history-dir /tmp/phase4ac-history \
  --production-db /path/to/production.db \
  --evaluation-time 2026-08-25T23:00:00Z \
  --attestation-output /tmp/phase4aj-attestation.json \
  --advancement-manifest-output /tmp/phase4aj-manifest.json
```

Add `--human-approval-artifact` only for an independently created approval. Publication uses
canonical JSON, temporary files, file and directory `fsync`, paired atomic replacement, refusal
of existing outputs unless `--replace` is supplied, and rollback/cleanup after failure.
