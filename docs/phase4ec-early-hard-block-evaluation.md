# Phase 4EC — Early Hard-Block Evaluation

Phase 4EC models moving complete and provably decisive hard blocks ahead of expensive
offline risk stages. Legacy and optimized decisions are produced from the same immutable
fixture and must remain exactly equal. The optimized model avoids only downstream work
after a decisive block or fail-closed incomplete-evidence refusal.

Non-decisive triggers cannot short-circuit. Block evaluation order is deterministic by
priority and identifier, and reason-code order follows that evaluation order. Work is
measured in deterministic units rather than wall-clock time. Invalid fields, duplicate
identities, malformed types, missing stages, and hash tampering fail closed.

The model creates no decisions, reserves no capital, accesses no connected system, and
authorizes no execution. Publication is atomic and artifact-only.
